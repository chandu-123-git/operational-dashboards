# Order Fulfillment Dashboard

A simple, interactive web application developed to demonstrate **Operational Dashboards** concepts under Phase 5 — Frontend & Operational Applications.

The application uses a warehouse order fulfillment scenario to help students understand how businesses monitor orders, track performance, and identify operational issues.

## Concepts Covered

| Topic | Concepts |
|---|---|
| Dashboard Fundamentals | Tables, Search and Filters, Pagination |
| Business Views | KPIs and Charts |
| Real-Time Operations | Live Data (Simulated) and Alerts |
| Role-Based Operations | Role-Specific Dashboards |

## Features

- Order table with search, filters, and pagination.
- Overdue order KPI and warehouse comparison chart.
- Simulated operational updates and alert history.
- Operations Manager and North Warehouse Operator views.
- Guided activities for practical learning.

## Tech Stack

HTML, CSS, and JavaScript.

## How to Run

Open `docs/index.html` in Chrome or Edge. No installation or backend is required.

## Project Status

The application currently uses manually advanced simulated updates. Automatic playback with Start, Pause, and Reset controls is the planned improvement.

The project is under review to ensure a clear, practical, and beginner-friendly student learning experience.
